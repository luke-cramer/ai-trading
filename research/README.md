# Research corpus (phase 1)

Raw output of the 18-agent research spike behind [../REPORT.md](../REPORT.md). Each file is one
researcher's beat, unedited. Claims are tagged [verified] / [anon] / [promo] as in the report.
The report's conclusions supersede anything here where they conflict (e.g. `strat-classic.md`
ranked turn-of-the-month #1; `seasonality-verify.md` refuted it).

| File | Beat |
|---|---|
| strat-classic.md | Classical strategies: trend, mean reversion, seasonality, factors, options |
| strat-crypto.md | Crypto strategies: carry, arb, market making, AMM LP |
| strat-ml.md | ML / RL strategies and the Numerai-style tournaments |
| llm-experiments.md | LLM-as-trader experiments, agent frameworks, real-money arenas |
| academic.md | Academic literature: decay, backtest overfitting, retail base rates |
| markets.md | Market/broker/data comparison: equities, futures, crypto, forex, options |
| crypto-us-venues.md | Onshore US crypto derivatives venues (Coinbase Derivatives, CME) |
| base-rates.md | Who wins: population studies, marketplace attrition, prop firms |
| track-records.md | Verified vs promotional track records; Numerai API pull |
| github.md | Open-source trading bot ecosystem telemetry |
| hn-forums.md | Hacker News / Elite Trader / QuantConnect forum accounts |
| podcasts-blogs.md | Practitioner blogs and podcasts (mostly [promo], used against interest) |
| seasonality-verify.md | Gap-fill: own replication of the turn-of-the-month effect (refuted) |
| gap-2.md | Gap-fill: onshore perp funding vs CME basis measurement |
| reddit-*.md | Reddit beats — API was down; contain no usable data |
